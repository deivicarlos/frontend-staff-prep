# Mission: Frontend Senior/Staff Engineering (React + TypeScript)

## Why

Carlos spent the last ~2 years managing rather than shipping. He wants to move back
to the IC track and land a **Senior or Staff Frontend engineer** role. He is employed,
so there is no deadline pressure — but resumes are already going out, which means the
first real interview could land next week or in six months. The job is therefore to be
**continuously interview-ready**, not to peak on a date.

Fullstack roles are the phase-two expansion (he has some Node experience). Frontend
depth comes first: get to genuinely strong there, then widen.

## Success looks like

- Can build a non-trivial React component from scratch in 45 minutes, narrating trade-offs, without reaching for docs on syntax.
- Can run a frontend system design round end to end (RADIO) on prompts like "design a news feed" or "design a design system" and lead the conversation rather than follow it.
- Can answer deep-dive questions on rendering, reconciliation, state ownership, the event loop, and TypeScript generics without hedging.
- Has a current mental model of what changed 2024–2026: React 19, Server Components, React Compiler, the death of manual memoisation, TanStack Query as default server state.
- Has 4–6 staff-level stories ready that convert the management years into an asset (influence, technical strategy, mentoring) rather than a gap to explain.
- Has one substantial public project that survives being read by an interviewer.

## Constraints

- Employed full-time; study time is irregular and energy-dependent. Some weeks are 10+ hours, some are 1.
- Because pace varies, every lesson must be self-contained and completable in one sitting (~30 min). No multi-session cliffhangers.
- Two years since last shipping React. Assume conceptual rust, not conceptual absence.
- Starting point is unmeasured — LR-0001 (the calibration) sets the real floor.

## Out of scope (for now)

- Backend depth beyond what a fullstack screen touches. Revisit once frontend is strong.
- LeetCode-style algorithms as a primary focus. Frontend loops rarely lead with them; revisit only if a target company demands it.
- React Native, mobile, and non-React frameworks (Vue, Svelte, Angular).
- Resume/LinkedIn/salary negotiation. Real work, but not *learning*, and not this workspace.
