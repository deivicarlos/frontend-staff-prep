# Exercise 0011: string drills

**50 minutes, 12 per problem.** No AI, no docs. Edit `strings.mjs`, then run `node check.mjs`.

The four LeetCode string problems most likely to follow "palindrome": 125, 680, 3 and 5. Each
has example checks, edge-case checks, and a large-input check that a brute-force solution fails.

## Protocol

1. Before you code each one, say the approach and its Big-O out loud. Two pointers? A sliding
   window? Expanding around each centre? That's what the interviewer grades first.
2. Finish one against its checks before you start the next. If you're stuck at 12 minutes,
   write the brute force, note its Big-O, and move on.
3. At the buzzer, note which ones aren't done.

**Don't open `AFTER-THE-TIMER.md` until the 50 minutes are up.**
