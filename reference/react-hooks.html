React hooks, one page

Beyond useState and useEffect: what each hook is for, the trap, and when not to use it. React 19.2.

Reference · from lesson 7 and lesson 8

The two models underneath

Render triggers: its own state was set · its parent rendered · a context it reads changed. Props changing isn't a trigger on its own. React compares with Object.is, and {}, [] and () => {} are new on every render.

One frame: handler → render → commit → useLayoutEffect → paint → useEffect (usually; it may run before the paint when an interaction caused it).

The hooks

HookForTrap
memo(C)Skipping a child's render when every prop is Object.is-equalUseless with inline objects or functions. Doesn't stop own-state or context renders
useMemoCaching a computed result, or keeping an object prop stablePointless without an expensive calculation, a memo child or a dependency array that reads it
useCallbackCaching the function itself for a memo child or an effect's depsOn a plain DOM element it does nothing
useRefA DOM handle, or a value handlers need but the screen doesn't (timer, controller, socket)Changing it doesn't render. Don't read or write it during render
useEffectEventReading the latest props and state inside an effect without restarting itNot for silencing the lint rule. Never in deps, never passed to children
useLayoutEffectMeasuring the layout and correcting it before the paint (tooltip, popover)Blocks the paint. Use useEffect otherwise
useTransitionMarking a setState you own as non-urgent and interruptible. isPendingNever on the state that controls a text input. Wrap setState after await in another startTransition
useDeferredValueRendering a slow child with a lagging copy of a value you receiveThe child must be memo. It isn't a debounce, so keep debouncing network calls
useSyncExternalStoreReading a store outside React (legacy app, browser API) without tearinggetSnapshot must return the same value while nothing changed. Keep subscribe stable
useActionState[state, dispatch, isPending] for a form or mutation. Calls run one after anotherCall dispatch from <form action> or startTransition
useOptimisticShowing the expected result while an Action runs. It reverts on its ownCall the setter inside an Action
useReading a promise (with Suspense) or a context, even inside an ifThe promise must be cached, not created during render
useReducerSeveral state fields that change together, through named actionsThe reducer must be pure
useContextValues that change rarely (theme, user, flags)Every consumer renders when the value changes
useIdStable unique IDs for aria-* and htmlForNot for list keys

React Compiler 1.0 (October 2025) inserts memo, useMemo and useCallback automatically. Without the compiler, first move state down or pass children.

Sentence to have ready: "Dependencies decide when an effect re-runs. memo decides whether a child skips its parent's render, and identity decides both. The rest is timing: layout effects before the paint, transitions after the urgent update."

Cold recall · 3 minutes

Cover the table. On paper, write the 12 hooks from memo to use, each with its trap in five words or fewer. Then check against the table. Every missing trap is the one to reread.
